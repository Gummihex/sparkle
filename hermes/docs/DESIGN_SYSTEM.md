# HERMES UI/UX Design System

Visual direction: dark technical command center, restrained neon accents, high contrast, dense but readable information architecture.

Primary screens:
1. Dashboard — global status, scenes, rooms, discovery and sync.
2. Discovery Center — Wi-Fi/LAN, BLE, Matter and Meta/platform paths.
3. Device Detail — state, capabilities, transport, diagnostics.
4. Room View — visual room layout and device groups.
5. Scene Studio — effect stack and timeline.
6. LED Mapping — physical/virtual LED zones.
7. Automation Studio — trigger/condition/action builder.
8. Graph — device/room/scene topology.
9. Stats — latency, health and network metrics.
10. Settings — integrations, security, AI and local model.

Logo concept: an abstract H/light bridge connecting four nodes, representing Hue/Nanoleaf/Govee/Twinkly while remaining manufacturer-neutral.

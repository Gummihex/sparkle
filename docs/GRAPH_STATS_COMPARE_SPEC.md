# Graph / Stats / Compare Specification

## Graph
Nodes: devices, rooms, groups, scenes, automations, physical LED segments and screen zones. Edges represent membership, targeting, synchronization and physical mapping. Provide filters by manufacturer, protocol, room and online state.

## Stats
Metrics: device count, online percentage, discovery time, command latency, command throughput, adapter error counts, reconnects, backend resource usage where available. Provide time windows and export without secrets.

## Compare
Compatibility matrix fields: manufacturer, model, discovery, authentication, local control, cloud/API, Matter, BLE, power, brightness, RGB, color temperature, effects, animation, individual LED, notes and verification date. Only verified capabilities are marked supported.

# HERMES LIGHT HUB — UI/UX Specification

## Visual language
Dark technical command-center; Material 3 foundations; high information density without clutter; responsive Windows desktop and Android mobile layouts.

## Brand
Working name: HERMES LIGHT HUB. Suggested mark: abstract H-shaped light bridge / four-node constellation. Primary UI surfaces should emphasize device state, rooms and scenes rather than manufacturer branding.

## Windows navigation
Dashboard / Devices / Rooms / Groups / Scenes / Effects / Automations / Screen Sync / Music Sync / LED Mapping / AI / Network Graph / Stats / Diagnostics / Integrations / Settings.

## Android navigation
Home / Devices / Rooms / Scenes / Automations / Favorites / Settings. Quick actions: All On, All Off, Gaming, Movie, Party, Relax, Night.

## Device card
Name, manufacturer/model, room, online state, protocol, power, brightness, color preview, supported effects and quick scene. Hide unsupported controls dynamically.

## Discovery Center
Tabs: Automatic, WLAN/LAN, Bluetooth, Matter, Meta/Home compatibility, IP, Manufacturer. Result cards expose evidence-based compatibility and an Add button.

## Dashboard widgets
System health, favorite scenes, rooms, device status, discovery, Screen Sync, Music Sync, automation status, AI status and diagnostics.

## Accessibility
Keyboard navigation, screen-reader labels where supported, scalable text, high contrast and status text in addition to color.

## Canva deliverables
Create editable brand board, logo directions, Windows dashboard mockup, Android dashboard, device-card variants, discovery wizard, room view, scene editor and LED mapping view. Export design tokens for implementation.
